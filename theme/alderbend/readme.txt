A from-scratch block theme for a small landscaping business. Concept demo for a made-up company.

== Description ==

Alderbend is a full-site-editing theme written from scratch: no starter theme, no framework, no page builder. It is a concept demo for a made-up business (Alderbend Landscape Co.) and has not been used for a real client.

Included:

* theme.json (version 3) with a palette, fluid type scale, spacing scale, shadows, and styling for core blocks
* 8 templates and 2 template parts, plus a Wide page template
* 16 block patterns (hero, facts strip, services, projects, process, seasonal calendar, service area, call to action, FAQ, service detail, about, contact, headings)
* 6 block styles (group card and soft panel, image arch, list checklist, paragraph kicker, button ghost)
* 2 dynamic blocks: Service area checker and Quote request form
* 1 style variation (Clay and sage)
* Self-hosted Fraunces and Figtree fonts (SIL Open Font License), original SVG illustrations

== Installation ==

1. Copy the `alderbend` folder to `wp-content/themes/`.
2. In Appearance > Themes, activate Alderbend.
3. Create pages named Home, Services, Projects, About and Contact (the header links expect those slugs), set Home as the front page and Projects as the posts page. `demo/seed.sh` in the repository does this with WP-CLI.
